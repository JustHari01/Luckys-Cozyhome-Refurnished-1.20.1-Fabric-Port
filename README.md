# Lucky's Cozy Home: Refurnished — Unofficial 1.20.1 Fabric Backport

A community backport of the Fabric release of Lucky's Cozy Home: Refurnished for Minecraft 1.20.1. The original mod adds functional furniture and home decorations.

## Features

- Chairs, couches, sofas, connected tables, shelves, drawers, and storage counters
- Lamps, wall and grandfather clocks, mirrors, sinks, bathtubs, fountains, and fountain spouts
- Cushions, dyeable furniture, a paint brush and dye vat, and a telescope
- The original furniture sets, recipes, models, textures, and sounds

The original textures and sounds are retained. The code and a small number of model definitions were adapted for Minecraft 1.20.1.

## Requirements

- Minecraft 1.20.1
- Fabric Loader 0.15.11 or newer
- Java 17 or newer
- Fabric API
- Install on both the client and server when joining a world that uses the mod
